Character files are from the owner's original Mustache repository and **are not claimed to be CC0**. The MIT license covers newly written source code, not these images.

Rooms, floors, wall segments, furniture, mustache projectiles, particles and other graphics are drawn procedurally with Canvas 2D; audio is synthesized at runtime with Web Audio. No third-party assets are bundled.

## Verified free candidates (not yet bundled)

- **Kenney Roguelike/RPG Pack** — CC0 interior tiles and furniture: https://kenney.nl/assets/roguelike-rpg-pack
- **Kenney Furniture Kit** — CC0 furniture with 2D views: https://kenney.nl/assets/furniture-kit
- **Kenney UI Pack** — CC0 menus and buttons: https://kenney.nl/assets/ui-pack
- **Kenney Interface Sounds** — CC0 sound effects: https://kenney.nl/assets/interface-sounds

Download the **individual free packs** rather than the paid all-in-one bundle. Verify the license on each specific pack and record the version when importing it. Isometric views are not always compatible with this game's top-down perspective.

## Mustache3

The future 3D game requires independent GLB models, animation rigs, skeletons and textures. The current 2D Sprite sheets are not 3D models.
